# The Blessed Electronics Shop — Production Vite Build

A client-side React + Vite + TypeScript + Tailwind CSS storefront for The Blessed Electronics Shop in Kimisagara Market, Kigali.

## Stack
React, Vite, TypeScript, Tailwind CSS, React Router, Redux Toolkit, redux-persist.

## Local
npm install
npm run dev

## Production
npm run build
npm run preview

## Vercel
This project includes `vercel.json` for Vite output and SPA route fallback.
Build command: `npm run build`
Output directory: `dist`
